# 散户看盘课 · Stocks

> 读懂一张行情页，比追一条消息值钱。

本项目面向**普通散户投资者**，用通俗的语言讲解股市常见术语、行情软件上各个字段的含义，以及如何看盘、怎样把零散的数字串成完整的判断。内容以真实行情截图为案例，从券商基金经理的视角逐项拆解，并附上计算过程，方便读者自己动手验证。

🔗 **在线阅读**：<https://jeffery812.github.io/stocks/>

### 第 01 讲涵盖

- **16 个信息区**：在截图上逐个标注，点击编号即可跳到对应讲解
- **价格类**：现价、涨跌额/涨跌幅、高/低/开、昨收、盘后价
- **估值类**：总市值、市盈率 TTM（以及公司亏损时怎么看估值）
- **活跃度**：量比、换手率、成交额，以及量价配合
- **图表**：分时走势、黄色均价线（VWAP）、坐标轴的对称规则、分时量柱
- **盘口与成交**：买一/卖一、逐笔明细、主动买卖、收盘集合竞价
- **美股特有规则**：红涨绿跌与美股习惯相反、无涨跌停、T+0、盘前盘后、冬夏令时
- **综合复盘**：把单个字段拼成积极信号、待验证项、风险提示
- **30 秒读盘五步法**与**八个常见误区**

### 第 02 讲涵盖

42 张名词卡片，每张都包含：一句话解释、计算公式、例子、**常见误解 vs 真相**、实操提示。页面支持搜索（按 `/` 聚焦）、按分类筛选，以及只看「最易误解」的名词。

- **价格与涨跌（7）**：昨收/开盘价、涨跌幅/振幅、涨跌停、高开低开/跳空缺口、除权除息、前复权/后复权、集合竞价
- **估值指标（7）**：市盈率 PE、市净率 PB、市销率 PS、PEG、总市值/流通市值、EPS/ROE、股息率
- **量能与资金（7）**：成交量/成交额、量比、换手率、内盘/外盘、主力资金净流入、委比/买一卖一、均价线
- **交易规则（10）**：T+1/T+0、手、交易费用、限价单/市价单（含挂单如何撮合成交）、ST/*ST/退市、限售股解禁、送股/转增、融资融券、做空/买空（含 Avanza 示例）、打新
- **图表与技术（5）**：K 线、均线 MA、支撑位/压力位、MACD/KDJ、牛熊市与震荡市
- **概念与心态（6）**：回撤/最大回撤、套牢/止损/补仓、仓位、利好兑现、指数/ETF/基金、基本面/技术面/消息面

两块重点内容：

- **估值尺子**：每个估值指标的卡片右侧都有一把尺子，标出合理范围、偏贵/偏便宜的分界线，以及常见陷阱（低 PS 陷阱、回购让 PB/ROE 失真等）。用 SpaceX、英伟达、谷歌、苹果、特斯拉、微软、CoreWeave 7 家公司做实例，可以按 Tab 逐只查看，也可以用「全部对比」点阵图并排比较。页面底部附 A 股主要行业 PE/PB 参考区间和数据来源。
- **回撤卡片**：回撤示意图、回本难度表（跌 50% 要涨 100% 才能回本），讲清楚回撤量的是复权股价、基金净值还是账户收益曲线，以及「股票的回撤 ≠ 你的回撤」。

页面末尾有 8 道自测题，答完会显示得分。
